História dos computadores

A palavra computador vem de computar, ou seja, calcular. Antes das máquinas eletrônicas, o ser humano já criava instrumentos para contar: o ábaco é um exemplo clássico.

A história costuma ser dividida em gerações, marcadas pela tecnologia usada para processar dados:

  1. 1ª geração (1940–1956): válvulas eletrônicas, como o ENIAC.
  2. 2ª geração (1956–1963): substituição das válvulas pelos transistores.
  3. 3ª geração (1964–1971): surgimento dos circuitos integrados.
  4. 4ª geração (1971–hoje): os microprocessadores e os computadores pessoais.

"A capacidade de armazenamento e a velocidade de processamento dobram a cada período, enquanto o custo cai." — uma leitura informal da Lei de Moore.

Curiosidade: o primeiro "bug"

Em 1947, engenheiros encontraram uma mariposa presa dentro do computador Harvard Mark II. O inseto foi colado no diário de bordo com a anotação "first actual case of bug being found". Daí vem o termo bug para erros de software. (Sim, é uma história real!)

E o "debug"?

Debugar é culpar o programador. Debugar é o processo de investigar e corrigir um defeito no código.

Unidades de medida

A menor unidade de informação é o bit. Um conjunto de 8 bits forma 1 byte. Também vale lembrar da notação científica em potências de 2: 210 = 1.024, então 1 KB = 1.024 bytes. Já a massa de um notebook moderno gira em torno de 1,3 kg, ou seja, quase 103 gramas.

Detalhe químico

O silício, base dos chips, e a água (H2O) usada na fabricação de semicondutores ilustram bem a relação entre hardware e química.

O que são Clients?

Client (cliente) é o dispositivo ou programa que solicita um recurso. Quando você abre o navegador e digita um endereço, o seu computador está agindo como cliente.

Exemplos de clients:

  • Navegadores: Chrome, Firefox, Edge, Safari.
  • Aplicativos: app de banco, Spotify, WhatsApp.
  • Ferramentas de linha de comando: URL acessada via cURL ou wget.

O cliente é responsável pela interface: ele apresenta a informação e envia os comandos do usuário para o servidor.

O cliente pede; o servidor responde. Guarde essa frase.

O que são Servers?

Server (servidor) é o computador ou software que armazena e entrega recursos para os clientes. Ele fica ligado 24 horas por dia, 7 dias por semana, esperando requisições.

Tipos comuns de servidores:

  1. Servidor web: entrega páginas HTML, CSS e JavaScript.
  2. Servidor de banco de dados: guarda e consulta informações.
  3. Servidor de arquivos: compartilha documentos e imagens.
  4. Servidor de e-mail: envia e recebe mensagens.

O ciclo requisição / resposta

  1. O cliente envia uma requisição (ex.: GET /index.html).
  2. O servidor processa o pedido.
  3. O servidor devolve uma resposta com o conteúdo e um código de status.
  4. O cliente renderiza o resultado na tela.

Os códigos de status mais famosos são 200 (sucesso) e 404 (não encontrado). Existe também o 500, que indica erro interno do servidor.

Como é a estrutura básica de um HTML?

Todo documento HTML segue um esqueleto simples. As partes principais são:

  1. <!DOCTYPE html> — avisa ao navegador que o documento usa HTML5.
  2. <html> — elemento raiz, com o atributo lang definindo o idioma.
  3. <head> — metadados: título, codificação e configurações.
  4. <body> — tudo o que o usuário vê na página.

A codificação UTF-8 é a mais recomendada, porque suporta acentuação e emojis. E o viewport garante que o site funcione bem no celular.

Sobre aninhamento

As tags devem ser fechadas na ordem inversa em que foram abertas. Escrever <p><strong>texto</p></strong> está errado; o correto é <p><strong>texto</strong></p>.

Entendendo a diferença entre listas ordenadas e não ordenadas

A diferença está no significado da lista, não apenas na aparência.

Lista não ordenada — <ul>

Usada quando a ordem não importa. Os itens aparecem com marcadores (bullets).

  • HTML
  • CSS
  • JavaScript

Lista ordenada — <ol>

Usada quando existe uma sequência obrigatória, como um passo a passo. Os itens aparecem numerados.

  1. Abrir o editor de código.
  2. Criar o arquivo index.html.
  3. Escrever a estrutura básica.
  4. Abrir o arquivo no navegador.

Dica: uma lista de compras é <ul>; uma receita de bolo é <ol>.

Saiba mais: MDN — elemento <ul> | MDN — elemento <ol>
