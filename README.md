# Trilha HTML - Dio.me

## Módulo 01 - Primeiros passos com HTML

Desafio de Projeto do Módulo I da trilha de HTML da [DIO](https://www.dio.me/).

O objetivo é elaborar um website com estrutura básica, utilizando todas as tags
aprendidas nas aulas práticas até então.

### Tags obrigatórias

| Tag | Onde foi usada |
| --- | --- |
| `<h1>` a `<h6>` | Título principal, seções e subseções |
| `<p>` | Todos os parágrafos |
| `<mark>` | Destaques de termos importantes |
| `<small>` | Observações e notas de rodapé |
| `<i>` | Termos em inglês (Clients, Servers, bullets) |
| `<u>` | Ênfase em trechos específicos |
| `<strong>` | Negrito com significado de importância |
| `<ol>` | Gerações dos computadores, tipos de servidor, passo a passo |
| `<ul>` | Índice, exemplos, listas sem ordem |
| `<li>` | Itens de todas as listas |
| `<a>` | Índice com âncoras, links externos e "voltar ao índice" |
| `<hr>` | Separação entre as seções |
| `<sub>` | Fórmula química H<sub>2</sub>O |
| `<sup>` | Potências de 2 (2<sup>10</sup>) |
| `<blockquote>` | Citações |

### Novas tags pesquisadas

| Tag | O que faz |
| --- | --- |
| `<font>` | Define cor, tamanho e fonte do texto. **Obsoleta** no HTML5 (use CSS). |
| `<del>` | Marca um texto como removido/riscado. |
| `<abbr>` | Indica uma abreviação; o texto completo aparece no `title` ao passar o mouse. |

> Observação: `<p>` já fazia parte da lista de tags obrigatórias e foi usada normalmente.

### Como visualizar

Basta abrir o arquivo `index.html` no navegador:

```bash
xdg-open index.html   # Linux
```
